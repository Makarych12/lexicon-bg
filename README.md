# Лексикон BG

Интерактивные карточки для изучения болгарской и словенской лексики: глаголы, спряжения, времена и грамматическая викторина.

Приложение помогает запоминать болгарские глаголы вместе с переводом, произношением (IPA) и примерами употребления во всех временах, а также проверяет знания через викторину по грамматике.

## Словенский блок

Переключатель «Болгарский / Словенский» в шапке открывает отдельный курс словенского языка по уровням A1–C1 (335 глаголов, ≈2800 примеров):

- вид глагола (dovršni / nedovršni / dvovidski), группа спряжения и чередования в основе;
- спряжение в единственном, двойственном (dvojina) и множественном числе в шести формах: sedanjik, preteklik, predpreteklik, prihodnjik, pogojnik, velelnik — с подсветкой окончаний и подсказкой-правилом;
- 6–11 контекстных примеров на глагол (словенский + русский, подсвеченная форма), озвучка через Web Speech API (`sl-SI`);
- у каждой карточки своя фотография с [Pexels](https://www.pexels.com) (подобрана по смыслу глагола, уникальна для каждой карточки, с подписью фотографа; при недоступности картинки показывается emoji-сцена);
- 3D-карточки с вкладками «Обзор / Спряжение / Примеры», фильтры по теме и виду, поиск, тёмная и светлая тема, трекер выученных глаголов (localStorage);
- викторина с вопросами по формам (включая двойственное число), виду, переводу и пропускам в предложении, с разбором ошибок в конце.

Данные словенских глаголов хранятся в `index.html` компактными строками-сидами (`slSeeds`), из которых формы и примеры строятся генератором на клиенте.

## Технологии

Статический сайт без сборки и зависимостей — весь код (разметка, стили, логика и данные по глаголам) находится в одном файле `index.html`. Внешне подключается только Tailwind CSS через CDN.

## Запуск локально

Открыть `index.html` в браузере, либо поднять любой статический HTTP-сервер в корне проекта, например:

```bash
python3 -m http.server 8000
```

и перейти на `http://localhost:8000/`.

## Деплой

Проект развёрнут на [Vercel](https://vercel.com) (конфигурация — `vercel.json`); поддерживается автоматически и через GitHub Pages.
