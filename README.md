# Glagolica

Статическое приложение для русскоязычного пользователя: словенский курс с 15-дневным интенсивом A1 и английский A1. Работает локально без API и сборки. Курс помогает освоить основное ядро A1 и показывает фактический результат заданий; прохождение за 15 дней не гарантирует уровень CEFR.

## Что есть в приложении

### Словенский

- **A1 Intensive**: 15 тематических дней от знакомства и дома до транспорта, двойственного числа, здоровья и итогового повторения. В обычном уроке 15 новых слов и 4–5 заданий на построение предложений. Если предыдущий день пройден менее чем на 65%, новых слов будет 10. В начале урока появляются до шести просроченных заданий; после долгого перерыва — до четырёх.
- **Активная практика**: ввод RU → SL, падежный тренажёр, Dvojina, сборка предложения, определение падежа, исправление ошибки, SL → RU и аудирование без показанного текста. Ответы сравниваются с локальными эталонами; для некоторых предложений предусмотрены варианты по роду. После ошибки показываются правильный вариант и подсказка по типу задания. Проверка детерминированная: свободные синонимы и произвольный порядок слов не всегда распознаются.
- **Повторение и ошибки**: для каждого учебного задания и навыка отдельно сохраняются интервалы, срок следующего повторения, число попыток и успешность. Ошибки образуют отдельную очередь. Кнопки быстрого урока дают короткую подборку просроченного, слабого и нового материала. Результат дня показывает процент по навыкам; статистика показывает сегодня, 7 дней, весь курс, закреплённые задания и серию дней. Дни 3, 5, 10 и 15 отмечены как контрольные точки A1 Core readiness; финальный день дополнен заданиями по падежам, dvojina, аудированию, чтению и диалогу.
- **Словарь и формы**: 335 глаголов A1–C1 с формами единственного, двойственного и множественного числа, плюс существительные и прилагательные с падежами. В карточке есть обзор, полная таблица, примеры и вкладка «Практика» с вводом форм. У девяти важных A1 глаголов, включая `biti`, `imeti`, `iti`, `delati`, `živeti`, есть вручную подобранные бытовые примеры. Добавлены эталонные A1 существительные `žena`, `polje`, `noč`, `konj`.
- **Диалоги и выживание**: 13 двухходовых бытовых диалогов с вводом ответа и 20 фраз Slovenia Survival для быстрой практики.
- **Дополнительно**: старое повторение карточек по упрощённому SM-2, викторина, Match, Sprint, алфавит, грамматический справочник, избранное, поиск, фильтры, фотографии, светлая и тёмная тема, ссылки на карточки и горячие клавиши.

### Английский

15 тематических уроков A1 с активным переводом RU → EN, повторением и личными ошибками. В словаре 225 тематических единиц с частью речи и озвучкой `en-GB`. Есть словарные игры Match и Sprint (они не влияют на интервальное повторение). Грамматический справочник охватывает `to be`, Present Simple, Present Continuous, Past Simple, future, вопросы, отрицания, артикли, множественное число, модальные и основные неправильные глаголы.

### Мост и разговорник

Раздел **EN ↔ SL** показывает 27 базовых пар с русским значением. Разговорник содержит 18 фраз для знакомства, вежливости, кафе, дороги, покупок, помощи и работы на трёх языках; словенский и английский озвучиваются через Web Speech API. После ответа можно экспериментально проверить произношение через SpeechRecognition; при отсутствии поддержки показывается подсказка. Доступность голосов зависит от браузера и установленных речевых пакетов.

## Данные и файлы

- `index.html` — существующий словенский движок, разметка и стили. Болгарский курс и его обработчики удалены.
- `data/course.js` — тематический план и задания на предложения для двух языков.
- `data/dialogues.js` — 13 сценариев и 20 фраз для бытовых ситуаций.
- `data/practice.js` — упражнения на исправление ошибок и определение падежей.
- `data/vocabulary.js`, `data/vocabulary-extra.js` — 225 базовых единиц A1 с темой по номеру урока, частью речи, уровнем и приоритетом.
- `js/learning.js` — учебный маршрут, проверка ответов, повторение, ошибки, английский словарь и новые EN–SL представления.
- `sw.js`, `manifest.webmanifest`, `icon.svg` — PWA. Оболочка и данные курса кэшируются при установке, фотографии — по мере просмотра.
- `tests/regression.py` — браузерная проверка эталонных словенских форм, загрузки курсов, сохранения прогресса и отсутствия ошибок JS.

## Прогресс в браузере

Новый учебный прогресс хранится в `localStorage` под `glagolicaLearningV1`. Старые словенские ключи (`lexiconSrsSl`, `lexiconSlLearned`, `lexiconSlFavorites`, настройки и рекорды игр) продолжают читаться. Старые болгарские ключи игнорируются и не используются. Если хранилище недоступно, занятия работают без сохранения.

## Запуск

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Сам `index.html` также открывается локально, но PWA и service worker требуют HTTP/HTTPS.

Для регрессионных тестов нужны установленные Chromium и ChromeDriver:

```bash
python3 tests/regression.py
```

## Развёртывание

Сайт не требует сборки. Раздайте корневую папку через любой статический хостинг; `vercel.json` подходит для Vercel. При обновлении офлайн-оболочки увеличивайте версию `SHELL` в `sw.js`.
